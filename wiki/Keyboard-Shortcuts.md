# Keyboard Shortcuts

| Key | What it does |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | Step through plates — anterior / posterior |
| <kbd>+</kbd> <kbd>−</kbd> | Zoom the plate in / out |
| <kbd>0</kbd> | Back to fit |
| <kbd>Home</kbd> <kbd>End</kbd> | Jump to plate 1 or plate 62 |
| <kbd>/</kbd> | Jump to the search box (and select what is in it) |
| <kbd>C</kbd> | Open or close the **Controls** panel beside the view |
| <kbd>F</kbd> | Give the view the whole window, and back |
| <kbd>?</kbd> | Open **About** |
| <kbd>Esc</kbd> | Drop the selection, clear a measurement, or close what is open |

## Mouse

| Action | What it does |
| --- | --- |
| **Hover** the plate | Read bregma / ML / DV under the pointer (with **Coords** on) |
| **Hover** a printed abbreviation | Read its full name |
| **Click** a printed abbreviation | Select that structure |
| **Double-click** the plate | Zoom in at that point |
| **Drag** the plate | Pan |
| **Click** twice with **Measure** on | Distance and approach angle between the points |

## In the 3D view

| Action | What it does |
| --- | --- |
| **Drag** | Orbit |
| **Shift-drag** or **right-drag** | Pan |
| **Wheel** | Zoom |

The same list is in the app, under **About** → *Getting around*.
